# Security policy

## Supported versions

Until the first stable release, security fixes are applied to the latest commit
on `main`.

## Reporting

Please use GitHub private vulnerability reporting for this repository. Include:

- affected command, API, or document;
- a minimal reproducer;
- expected and actual security behavior;
- impact and any suggested mitigation.

Do not include real credentials, customer data, or production receipts.

## Important limitation

BatasAksi is a reference implementation, not a complete production security
boundary. Review [the threat model](docs/THREAT-MODEL.md) before integrating it.
